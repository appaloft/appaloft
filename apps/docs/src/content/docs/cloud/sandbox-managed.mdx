# Cloud 托管 Sandbox

本页在开源 / 自托管文档构建中只提供占位说明。完整的 Cloud 托管 Execution Sandbox 准入、配额、凭据代理与生命周期说明，请查看官方 Cloud 文档：

[https://docs.appaloft.com/cloud/sandbox-managed/](https://docs.appaloft.com/cloud/sandbox-managed/)

自托管 Appaloft 仍然提供公共 Sandbox / Agent Workspace API；Cloud 额外提供托管 provider、组织权限与运营保障，这些不属于 Community 发行版。
