Appaloft Cloud 是在开源 Appaloft 之上提供的托管服务,面向不想自己运维控制面、数据库和后台调度器的团队。它复用完全相同的项目、服务器、环境、资源和部署模型——迁移到自托管,或从自托管迁移过来,都不需要改变使用方式。

这个分组只保留导航占位,让 Cloud 专属能力在开源文档站里可见,但不重复维护两份内容。Cloud 专属能力的完整说明——包括[权限与 RBAC](/docs/cloud/permissions/)和[托管 Sandbox](/docs/cloud/sandbox-managed/)——请前往官方 Appaloft Cloud 文档站查看。

对于本仓库覆盖的开源核心能力(部署、服务器、配置、访问、故障排查、Agent 集成),本站的其余分组就是完整且权威的参考。
