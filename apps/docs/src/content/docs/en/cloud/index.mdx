Appaloft Cloud is a managed service built on top of open-source Appaloft, for teams that don't want to operate their own control plane, database, and background schedulers. It reuses the exact same project, server, environment, resource, and deployment model — migrating to self-hosted, or from self-hosted to Cloud, requires no change in how you use it.

This group only keeps a navigation placeholder, so Cloud-exclusive capabilities stay visible in the open-source documentation site without duplicating a second copy of the content. For the full description of Cloud-exclusive capabilities — including [Permissions And RBAC](/docs/en/cloud/permissions/) and [Managed Sandbox](/docs/en/cloud/sandbox-managed/) — see the official Appaloft Cloud documentation site.

For the open-source core capabilities covered by this repository (deployment, servers, configuration, access, troubleshooting, agent integration), the rest of this site is the complete and authoritative reference.
