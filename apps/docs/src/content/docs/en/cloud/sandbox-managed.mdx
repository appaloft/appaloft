# Cloud managed Sandbox

This page is a placeholder in open-source / self-hosted docs builds. For the full Cloud managed Execution Sandbox guide — tenant admission, quota, credential brokerage, and hosted lifecycle — open the official Cloud docs:

[https://docs.appaloft.com/cloud/sandbox-managed/](https://docs.appaloft.com/cloud/sandbox-managed/)

Self-hosted Appaloft still exposes the public Sandbox and Agent Workspace APIs; Cloud adds hosted provider, authz, and operational guarantees that are not part of the Community distribution.
